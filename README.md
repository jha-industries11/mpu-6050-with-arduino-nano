# mpu-6050-with-arduino-nano
In this project i will show you how to create amazing projects with arduino nano and the mpu 6050 gyroscope.I will show the testing and the final project and explain u the code and the hardware.
first of all you should be sure with which gyroscope are you using coz in this project i have specifically used the mpu 6050 gyroscope which has the pins'vcc,gnd,scl,sda,int,xcl,xda,and ad0.
this project is programmed in arduino ide (c+)
